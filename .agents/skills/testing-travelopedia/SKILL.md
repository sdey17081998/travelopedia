# Testing Travelopedia

Next.js 16 (App Router) + React 19 + Tailwind v4 tour-booking demo. Bookings and UPI transactions are logged to a SQLite DB via Prisma 7 (better-sqlite3 adapter).

## Run locally

```bash
cd travelopedia
npm install            # postinstall runs `prisma generate`
npm run dev            # http://localhost:3000  (build runs `prisma generate && next build`)
```

Local DB lives at `prisma/dev.db`. On Vercel the DB is ephemeral at `/tmp/travelopedia.db` and resets per cold start, so **prefer local testing for DB-logging verification**. The Vercel preview is also typically behind Deployment Protection (login wall).

## Booking flow (5 steps)

1. Open a tour, e.g. `/tours/darjeeling-queen-of-hills` → "Book this tour" → `/book/<slug>`.
2. Step 1 Trip details (travelers, add-ons) → Step 2 Traveler info (name/email/phone) → Step 3 Review.
3. **"Proceed to payment" (step 3→4) writes the Booking row** (POST `/api/bookings`, status `pending`).
4. Step 4 Payment shows UPI ID `travelopedia@okaxis` + QR + app picker (GPay/PhonePe/Paytm/BHIM).
5. **"Pay …" (step 4→5) writes the Transaction row** (POST `/api/transactions`) and flips the booking to `confirmed`. Confirmation screen shows the reference `TRP-XXXXXX`.

## Verify DB logging

- UI: open `/admin` (server component reading Prisma directly). Should list each booking with its linked transaction, totals in ₹, and status badge (pending/confirmed).
- Direct query (no `sqlite3` CLI installed; use node + better-sqlite3):
  ```bash
  node -e "const D=require('better-sqlite3');const db=new D('prisma/dev.db');console.log(db.prepare('SELECT reference,total,status FROM Booking').all());console.log(db.prepare('SELECT reference,upiApp,upiId,amount,status FROM \"Transaction\"').all());"
  ```
- To reset to an empty state before a clean test, delete rows (or remove `prisma/dev.db` and restart so the schema bootstraps via CREATE TABLE IF NOT EXISTS).

## Pricing math (for assertions)

total = price/person × travelers + (sum of selected per-person add-ons) × travelers.
Example: Darjeeling ₹18,500 × 2 + (Insurance ₹1,200 + Airport transfer ₹900) × 2 = **₹41,200**. Insurance + Airport transfer are ON by default, Private guide OFF; default travelers = 2.

## Gotchas

- Prisma 7: datasource URL is in `prisma.config.ts`, NOT schema.prisma. Client is generated by `prisma generate` (wired into `build` + `postinstall`); a missing client breaks the build/typecheck.
- `better-sqlite3` is native — it's in `serverExternalPackages` in `next.config.ts`. If DB calls fail at runtime, check that config.
- AGENTS.md warns this is Next.js 16 with breaking changes; read `node_modules/next/dist/docs/` before code changes.
